JustType System Navigation Icon Proposals

Draft icon set for compact eight-key System Navigation overlays. Each sample is shown inside a key-sized box, with labels for review only. The icon language uses heavy simple strokes, small context marks, and minimal text so symbols remain legible when the floating keyboard is small.
