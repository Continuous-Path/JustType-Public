SETTING NAME: Letter Arrangement
NEW SETTING NAME:
INFO PROMPT: Choose between Optimized (letters grouped by frequency for faster typing) and Alphabetical (letters in A-Z order for a more familiar appearance). The Optimized arrangement is more efficient, requires fewer keystrokes, and is recommended for most people. Changing this is reversible and can be tested before confirming. 

SETTING NAME: [NONE: NEW SETTING]
NEW SETTING NAME: Optimized Letter Arrangement Language
INFO PROMPT: It is likely that most people will first become familiar with the letter arrangement for their own language, and that this arrangement will be by far the most familiar keyboard for most individuals.  Multi-lingual individuals will likely want to use more than one language.  The Optimized arrangement for some languages may differ only slightly, so that it may be advantageous to continue to use the arrangement with which they are most familiar: the arrangement for their native language.  Such individuals can select their native language for this setting.  Another setting option is "Use Native Keyboard" in which case the Optimized arrangement will be the arrangement developed for the current language being used.  In some case, where a language has a different alphabet, selecting that language as the Typing Language will automatically force this setting to change to match the Typing Language.

NOTE: This setting was moved from the "JustType Settings" page to the "Vocabulary Management" page where it sits next to "Enable Accented Next-Letter Hints" under a single "Next-Letter Hints" section.
INFO PROMPT: As you are typing a word, JustType figures out all the possible words in the database that match the keys you have typed so far.  JustType can also determine what all the letters are that come next in any of the words that you might be typing.  When "Next-Letter Hints" is ON, JustType will "highlight" each of those letters on the keyboard by displaying these "Next-Letters" in bold font, while all other letters are"grayed out."  Turning "Next-Letter Hints" ON can help guide you as you spell longer words - if you have entered the correct key sequence so far, the next letter of your word will be highlighted.  If your next letter is "grayed out," you probably need to back up a little and fix a typing mistake (or add a new word that is not yet included in the database).  When ALL of the letters on a key are "grayed out" it will not do anything if pressed (and if "Error Beep" is ON, you will hear a short beep that can help alert you to this).

SECTION NAME:  --- Other Input Methods ---
NEW SECTION NAME:  --- Adaptive Input Methods ---
INFO PROMPT: There are four adaptive input methods that can be used to activate keys, that can be used in addition to any touchscreen method that might be used.  These adaptive methods include:
(1) Head Tracking (move a cursor in response to head movement)
(2) Joystick (requires an external joystick)
(3) Single-Switch Scanning (single-switch linear scanning of the 8 keys)
(4) Two-Switch Selection (a sequence of three activations of either of two switches immediately selects one of the 8 keys)
(5) (None - use only one of the touchscreen methods, either Direct Selection or Directional Selection).

SETTING NAME: Head Tracking
NEW SETTING NAME:
INFO PROMPT: The Head Tracking input method requires that the "HeadBoard" application (also available from the Continuous Path Foundation) is also installed and configured on your device (just follow the prompts when installing HeadBoard).  The HeadBoard app uses the front-facing camera to track your head movement, and move an on-screen mouse cursor in response to it.  This cursor appears whenever you are operating any software on your device OTHER THAN THE JUSTTYPE KEYBOARD ITSELF.  When the cursor enters the keyboard, its exact location is no longer displayed.  This is because keys are pressed just by moving your head in the general direction of the key you want to press.  You don't have to be very precise - just move your head from the "resting area" (the center of the keyboard) in the direction of the key (the "compass direction" of the key from the center of the keyboard).  As soon as the key turns green, move back toward the center.  The key will be activated, and you can move directly toward the next key you want to press.  If you accidentally activate the wrong key, just go up to the "Undo" key to remove that keystroke.

SETTING NAME: Joystick
NEW SETTING NAME:
INFO PROMPT: The Joystick input method requires that you use an external Bluetooth joystick installed and configured on your device.  JustType will display an on-screen mouse cursor that will move in response to how you move the joystick.  This cursor appears whenever you are operating any software on your device OTHER THAN THE JUSTTYPE KEYBOARD ITSELF.  When the cursor enters the keyboard, its exact location is no longer displayed.  This is because keys are pressed just by moving the joystick in the general direction of the key you want to press.  You don't have to be very precise - just move from the "resting area" (the center of the keyboard, where the joystick is close to its center position) in the direction of the key (the "compass direction" of the key from the center of the keyboard).  As soon as the key turns green, move back toward the center.  The key will be activated, and you can move directly toward the next key you want to press.  If you accidentally activate the wrong key, just go up to the "Undo" key to remove that keystroke.

SETTING NAME: Single Switch Scanning
NEW SETTING NAME:
INFO PROMPT: Single-Switch Scanning displays the keyboard as one or two horizontal rows of keys that are scanned (highlighted) in sequence.  This allows you to close a single switch to activate the key that is currently highlighted.  Because the JustType keyboard only has eight keys, it is easier and more efficient to just scan all the keys in sequence rather than arrange them in multiple rows and use some kind of "row-column scanning" that might be used on a keyboard with many more keys.  The switch itself can be an external Bluetooth switch that has been installed and configured on your device.  If you don't use an external switch, you can set up the "Touchscreen Switch" so that you can use the bottom of the device screen as your switch and just tap the screen to close the switch.

SETTING NAME: Two-Switch Selection
NEW SETTING NAME:
INFO PROMPT: Two-Switch Selection is different from scanning methods: it uses two different switches (a "green" and a "red" switch, though the actual color of the switches doesn't really matter), and selecting a key requires a sequence of three switch hits on one of the two keys.  The keys are each highlighted in either green or red - and all you do is hit the switch that matches the color of the key you want.  At the start of a sequence, four of the keys are highlighted in green and the other four in red.  Let's say the key you want to press is highlighted in green at this point - then you start by hitting the green switch.  Then the four keys that were red stop being highlighted, and two of the keys that were green now turn red.  Again, just keep hitting the switch that matches the color of the highlight on your key.  After the second switch hit, there will only be two keys left - a green one and a red one - you know what to do.  At first, you will find the changing highlighting helpful to guide you.  But there is also a setting ("Show color code band at bottom") that you can turn ON whenever you want.  This will display a rectangle below each key with three color bands, either green or red.  The left-to-right sequence of color bands shows the sequence of switches that activate that key.  Then you don't have to watch the key and think about it: if the band shows green then red then green, just hit the switches green-red-green without waiting, and the key will be activated.

SECTION NAME: --- Touchscreen Input Methods ---
NEW SECTION NAME:  

INFO PROMPT: NOTE: When Directional Selection (or the Touchscreen Switch) is turned ON below, JustType will "capture" all of the touch actions that are performed on all (or part) of the touchscreen.  When this is happening, you are not able to touch and interact with other UI controls that may be displayed on the screen.  If you or someone else needs to operate your device and thus needs to be able to interact with the screen, the simplest approach is to open the Functions keyboard and activate the "HIDE KEYBOARD" function.  When the keyboard is hidden, this screen "capture" is paused so someone can interact as usual with whatever is shown on the screen.  This also means that Directional Selection (or the Touchscreen Switch) will no longer work until the keyboard is displayed again.  The simplest way to bring the keyboard back is by simply touching a text field.  If there is a need to also enter text while Directional Selection (or the Touchscreen Switch) is OFF, first hide the keyboard with the "HIDE KEYBOARD" function, then go to the system settings and turn Directional Selection (or the Touchscreen Switch) OFF in the JustType settings.  When you are done, just go back to settings and turn Directional Selection (or the Touchscreen Switch) back ON again.

NEW SETTING NAME: Direct Selection 
INFO PROMPT: When ON, you can tap directly on each key to activate it. This is the default touch-screen input method. At least one of Direct Selection or Directional Selection will always remain enabled so a teacher or clinician can interact with the device directly.

SETTING NAME: Directional Selection
NEW SETTING NAME:
INFO PROMPT: When this method is ON, keys can be activated by swiping anywhere on the keyboard and tracing a stroke in one of the 8 possible directions (toward any of the 8 compass points).  A stroke of almost any length, anywhere on the keyboard, will activate the key that is in the same direction relative to the center of the keyboard. For many people, this can be much easier and quicker than having to precisely tap a specific key. At least one of Direct Selection or Directional Selection will always remain enabled so a teacher or clinician can interact with the device directly.

SETTING NAME: Corner Bias
NEW SETTING NAME:
INFO PROMPT: Adjusts the apparent relative size of diagonal/corner keys. The keyboard is like a pizza with eight "slices" corresponding to the 8 keys, where you select a key by moving up into that "slice."  Values above 1.0 make it easier to reach corner keys - the corner "slices" become bigger; values below 1.0 favor the cardinal directions (up, down, left, right).


SECTION NAME:  [MISSING - THIS IS A NEW SECTION] 
NEW SECTION NAME:  --- Zone Thresholds ---

INFO PROMPT: The relative size of the center region where head movement has no effect - where you can just "rest" without trying to activate a key, and without worrying about activating a key unintentionally. A larger Resting Zone requires more head movement away from the center to get to where the surrounding keys start to respond to your head movement. Increase the size if the keys start to activate even though you are just trying to rest in the middle.  The boundary of each Zone is set as a fraction between 0.0 and 1.0, with 0.0 at the center of the keyboard and 1.0 at the very edge.  
 
SETTING NAME: Active Zone (Dead Zone < Active Zone < Exit Zone). The maximum value for Active Zone is 0.75
NEW SETTING NAME: Active Zone (Resting Zone < Active Zone < Exit Zone)
NOTE: The maximum value for Active Zone (0.75) is enforced by the slider and is not part of the displayed setting name.
INFO PROMPT: The relative distance that you have to move away from the center in order to activate a key. When you enter the Active Zone for a key, the key will turn green. After you enter the Active Zone and a key turns green, you just move back toward the center to activate the key. Decreasing the Active Zone makes it so that you can activate keys with less head movement, but may increase the chance that a key will be accidentally activated.

SETTING NAME: Exit Zone (Active Zone < Exit Zone < 1.0)
NEW SETTING NAME:
INFO PROMPT: The relative limit that defines the outer boundary for head movement within the keyboard region. You can pause Head-Tracking by turning your head to the right until the you reach the boundary of the Exit Zone, and then keep your head turned until the Exit Delay time elapses. The keyboard border will start flashing when you reach the Exit Zone. Decrease the size of the Exit Zone to reduce how far you need to turn your head to pause or leave the keyboard.  When you move upward (instead of to the right) into the Exit Zone, you can move the cursor out of the JustType keyboard. The keyboard border will start to flash, and then the cursor will appear in the region above the keyboard once the Exit Delay time elapses.  

SETTING NAME: Key Activation Threshold (0% - 100%)
NEW SETTING NAME:
INFO PROMPT: Once a key turns green and you start moving back toward the center, this threshold determines how far you must move back before the key activates. A lower value means keys will be activated more quickly, since it will happen before you have to move very far back toward the center. Setting this value to 100% means that you have to go all the way back to the start of the Active Zone in order to activate the key.

SETTING NAME: Exit/Pause Keyboard Delay (2 - 5 sec)
NEW SETTING NAME: Exit/Pause Keyboard Delay Time (2 - 5 sec)
INFO PROMPT: The number of seconds that the cursor must remain in the Exit Zone (with the keyboard border flashing) in order to pause or exit.  If the keyboard border starts flashing but you don't want to exit or pause, just move your head back toward the center to continue using the keyboard.  Once the keyboard border has flashed for the Exit/Pause Keyboard Delay Time, JustType will either (a) pause head tracking and display "Head Tracking Paused" (moving to the right) or (b) exit the keyboard into the region above (moving upward).  Reverse the process, moving all the way to the left to resume typing ("un-pause"), or move down to make the cursor "push against" the top border of the keyboard to re-enter the keyboard.  Increase the Exit/Pause Delay time (or the Exit Zone size) if pausing/exiting happens too easily.

SETTING NAME: Corner Bias
NEW SETTING NAME: Corner Weighting
INFO PROMPT: Adjusts the relative sensitivity of diagonal/corner keys (the "ordinal" directions - Northeast, southwest, etc.) compared to "cardinal" keys (straight up/down or left/right - North, South, East, West). For some people, corner keys seem harder to trigger than the straight up/down/left/right keys.  Values above 1.0 make it easier to reach corner keys - they become relatively bigger targets relative to other keys.  Values below 1.0 do the opposite and make the cardinal directions (up, down, left, right) become bigger targets.

SETTING NAME: Vertical Sensitivity
NEW SETTING NAME:
INFO PROMPT: This adjusts the relative ease with which up/down head movement moves the cursor vertically compared to how much left/right movement moves the cursor horizontally. Increase if vertical movements feel sluggish compared to horizontal (or simply if it is more difficult to move your head up and down). Values above 1.0 amplify vertical motion, and values below 1.0 amplify horizontal motion.

SETTING NAME: Response Curve
NEW SETTING NAME: Responsiveness 
INFO PROMPT: Controls how much (or how fast) the cursor moves in response to head movement.  Values above 1.0 make the cursor move faster/farther (easier to move larger distances). Values below 1.0 result in slower/smaller cursor movements (for more precise targeting).

SETTING NAME: Debug Overlay
NEW SETTING NAME:
INFO PROMPT: When ON, JustType a diagnostic overlay on the keyboard with zone boundaries, cursor position, and frame rate information. Useful for troubleshooting head tracking behavior.

INFO PROMPT (for "Show Accented Hints"): If "Enable Module" is checked for a row, then you can also check "Show Accented Hints" so that JustType will display Accented Hints to make it easier to type words that are in the module.  

COLUMN HEADING:  Accented Word Count
NEW COLUMN HEADING: 
INFO PROMPT (for "Accented Word Count"): The "Accented Word Count" shows the number of words from that module that will trigger Accented Hints when they are typed.  This is also determined by other settings (on the Vocabulary Management page) that can limit how many words trigger Accented Hints.  Restricting the number of Accented Hints words can make the Accented Hints that ARE triggered more effective.  

ROW HEADING:  JustType Main Database
NEW ROW HEADING: 
INFO PROMPT (for "JustType Main Database"): The "JustType Main Database" is one of the three standard JustType vocabulary modules.  This is the word dictionary containing all the words (in the language that you have selected) that you can spell by using JustType. In the case of English, this includes almost 51,000 words. Turn this OFF only if you want to limit the words that can be generated to only those contained in selected vocabulary lists (and/or Custom Words).  You can also change the settings on the Vocabulary Management page to limit which of these words can be spelled.  

ROW HEADING:  Custom User Words
NEW ROW HEADING: 
INFO PROMPT (for "Custom Words"): The "Custom User Words" module is the second of the three standard JustType vocabulary modules.  This module includes all the words that you have added manually (via the Add New Word function on the Navigation page). These would include words such as unusual names that are not in the JustType Main Database.  

ROW HEADING:  Abbreviations/Phrases
NEW ROW HEADING: 
INFO PROMPT (for "Abbreviations/Phrases"): The "Abbreviations/Phrases" module contains the multi-word phrases or sentences that you have added manually to the dictionary (via the Add New Phrase function on the Navigation page).  When you use the Add New Phrase function, you also choose an abbreviation that you type to recall the phrase.  For example, you could add the phrase "Call me back later. " with the abbreviation "CMBL", and then recall the phrase by just typing "CMBL". 

ROW HEADING:  (Past Vocabularies)
NEW ROW HEADING: 
INFO PROMPT (for "(Past Vocabularies)"): The "(Past Vocabularies)" module is a dedicated module that can be used to accumulate words from all of the past Vocabulary Modules that no longer need to be kept as separate, active modules.  There is a limit of 28 slots for Vocabulary Modules that can be defined at any one time.   When all (or most) of the words in a module have already been learned, you can "recycle" that slot (there is a limit of 28 Vocabulary Modules at any one time) and use it to load a new set of vocabulary words.  The no-longer needed vocabulary can be merged into "(Past Vocabularies)" which can be Enabled to make all of the previously learned words active.  For some, this may be a better option than Enabling the JustType Main Database, which might result in too many words being active at once.

INFO PROMPT (for "Export Usage for Selected Vocabularies" heading): You may find it useful to be able to see which words are included in which Vocabulary modules.  The Export feature allows you to select specific Vocabulary Modules and export all of the words they contain to a text file.  The modules that will be exported are all of the modules that have the "Export Vocabulary" column checked on the Manage Vocabularies table above.  You can also limit the words that are exported based on how many times they have actually been used by typing them in with the JustType keyboard.  Note that, for each word exported, the export file will also show how many times that word has been typed.  You can choose to export only those words:
(1) Never: only words that have never been typed.
(2) At Least Once: only words that have been typed one or more times.
(3) At Least ___ Times: only words that have been typed at least the number of times that you select with the slider.
(4) All Words: all the words in the module(s) will be exported.

INFO PROMPT (at the top of the "Manage Vocabularies" page): This page allows you to do three different things to set up and manage Vocabulary Modules in JustType: 
(1) Create a new Vocabulary Module by importing all of the words contained in a file.  Note: The "CHOOSE FILE TO IMPORT" button will be grayed out if all 28 Vocabulary Module slots are already used.  If so, you simply need to Merge or Delete an existing Vocabulary Module before creating a new one.  
(2) Merge two existing Vocabulary Modules into a single module to free up one of the 28 available slots for modules.  Alternatively, any module can be freed up by merging its contents into the dedicated "(Past Vocabularies)" module.  
(3) Simply Delete the no-longer-needed Vocabulary Module.  Note that this simply frees up the Vocabulary Module slot - the words that it contained will still be present in the database, and can still be typed.  

To create a new Vocabulary Module: 
(1) Create a plain text file containing the list of words you want to include in the module.  This file can be on your device or in a Google Drive folder that you can access from your device.  By default, the Vocabulary Module will be created with the same name as this text file. 
(2) Press the "CHOOSE FILE TO IMPORT" button and select the text file you created. 
(3) The name of the file will be shown as the name that will be used for the module.  If you want, you can edit it to be something different.  
(4) Press the "IMPORT SELECTED FILE" button to create the new vocabulary module.

(2) Choose one (or more) Vocabulary Modules to be merged from the list by checking the box in the "Merge From" column. 
(3) Press the "MERGE SELECTED VOCABULARIES" button.

INFO PROMPT (next to the word "Delete" in the "Select Vocabularies to Merge, Delete or Export" heading): 
To Delete existing modules: 
(1) Choose one (or more) Vocabulary Modules to be Deleted from the list by checking the box in the "Delete Vocabulary" column. 
(3) Press the "DELETE SELECTED VOCABULARIES" button.

INFO PROMPT (shown beneath the "Backup & Restore" heading): 
You can completely backup JustType, including everything you have added or modified: Vocabulary Modules, Custom Words, Abbreviated Phrases, all of your settings, and all of the modifications that are made to the Main JustType Database to reflect how your individual use of JustType.  All of the data is written to a folder that you select - either on your device or in a Google Drive folder that you can access.  Then later, if you need to, you can use the files saved in the folder to restore JustType, or set JustType up exactly the same way on a different device.  Note: If you are helping more than one individual, setting up JustType on different devices, then at the bottom you can turn �Use Advanced Backup & Restore" ON - otherwise, keep things simple and leave that setting OFF.  
To create a backup (or update an existing one to reflect additional changes):
(1) Press the "CREATE BACKUP NOW" button.  If you have alreaady backed up JustType before, this will update that backup to include all the changes that may have happened since the last time JustType was backed up.  You are all done! Steps (2) - (4) only happen the first time you backup.  

(2) If you have not created a backup before, the "CREATE BACKUP NOW" button will take you to a standard Android dialog where you can select the folder to store the backup.  Navigate to the folder and press the "Use this folder" button.  If/when a prompt appears asking for permission to "Allow JustType to access files in JustType backups?", press "Allow". 
(3) You will return to the previous screen, which will show the selected folder.  In the future, you will also see the date and time of the last backup created in the folder. 
(4) Press the "CREATE BACKUP NOW" button again to create a complete backup in the selected folder.  This will automatically be the backup that will be used if you later want to restore JustType.  

INFO PROMPT (shown above the "RESTORE FROM BACKUP" button): 
If something has happened to your device that has, for example, forced you to re-install JustType, you may want to restore your JustType data from a previous back-up.  Please be aware, if you haven't lost your data and you do this, you will lose any changes in your data since the backup was created.  But if you need to restore your data from a previous backup:
(1) Press the "RESTORE FROM BACKUP" button.  (It will be greyed out if you haven't created a backup yet.) 
(2) A prompt will pop up, asking "Restore backup? This will overwrite current data.  A restart may be needed to reload data."  As long as you are sure you want to do this, press "RESTORE".  


SETTING NAME: Use Advanced Backup & Restore
NEW SETTING NAME: 
INFO PROMPT: When you turn "Use Advanced Backup & Restore" ON, you are able to create and load different back-ups of JustType that may be used on different devices.  This can be helpful if, for example, you are a teacher or technical support person, especially since these backups can be created on a shared Google Drive.  This means you can back up someone's device to a shared drive, load that backup into your device and edit it (for example by creating and adding new Vocabulary Modules, Custom Words, Abbreviated Phrases or adjusted Settings), and then save it and reload the edited version from the individual's device. 

If you are just using JustType for yourself, it is probably best to just leave the "Advanced" mode turned OFF.  Then you will always backup to the same location, and if needed, restore from the latest backup.

INFO PROMPT (shown beneath the "Backup & Restore" heading when "Use Advanced Backup & Restore" is ON, replacing the simple-mode page-level prompt):
With "Use Advanced Backup & Restore" ON, you can keep more than one backup of JustType and switch between them.  Each backup lives in its own folder, and JustType remembers all of the folders you have used.  This is helpful, for example, if you are a teacher or technical support person setting up JustType on more than one person's device, or if you want to keep separate backups for different users or different stages of a setup.  The "Previous Backups" list below shows every backup folder JustType has created or used, with the date and time of the most recent backup in each folder.  Pick a folder from the list - or press "CHOOSE/CREATE NEW BACKUP FOLDER" to add a new one - to choose which backup to update or restore from.

INFO PROMPT (shown beneath the "Previous Backups" heading):
This list shows every backup folder JustType has created or used, sorted with the most recent backup at the top.  Each row shows the folder location, the date and time of the last backup made there, and a checkbox to select that folder as the current target for any backup or restore operation.  The most recent backup is selected as the default.  Pressing "CREATE BACKUP NOW" updates the backup in whichever folder is currently selected, and pressing "RESTORE FROM BACKUP" loads JustType with the data from that folder.  When the list is empty (no backup folders have been chosen yet), "CREATE BACKUP NOW" and "RESTORE FROM BACKUP" are both grayed out until you press "CHOOSE/CREATE NEW BACKUP FOLDER" and pick a folder.

INFO PROMPT (shown above the "CHOOSE/CREATE NEW BACKUP FOLDER" button):
Press this button to pick a folder for a new backup, or to add an existing folder that JustType has not used before.  This will take you to a standard Android dialog where you can navigate to the folder and press "Use this folder".  If/when a prompt appears asking for permission to "Allow JustType to access files in JustType backups?", press "Allow".  The folder you chose is then added to the "Previous Backups" list and selected as the current target.  Press "CREATE BACKUP NOW" to put a fresh backup into the new folder.  Any earlier backups in other folders are preserved exactly as they were.  This button is always available, so you can add another folder at any time.

INFO PROMPT (shown above the "CREATE BACKUP NOW" button when "Use Advanced Backup & Restore" is ON, replacing the simple-mode prompt):
Press this button to update the backup in the folder currently selected in the "Previous Backups" list.  All of your current data - Vocabulary Modules, Custom Words, Abbreviated Phrases, settings, and all of the modifications that reflect how you individually use JustType - is written to that folder, replacing whatever was there before.  Other backups in other folders are not touched.  This button is grayed out until a folder is selected in the list; the list is empty until you press "CHOOSE/CREATE NEW BACKUP FOLDER" for the first time.

INFO PROMPT (shown above the "RESTORE FROM BACKUP" button when "Use Advanced Backup & Restore" is ON, replacing the simple-mode prompt):
Press this button to load JustType with the data from the backup folder currently selected in the "Previous Backups" list.  A prompt will pop up, asking "Restore backup? This will overwrite current data.  A restart may be needed to reload data."  As long as you are sure you want to do this, press "RESTORE".  This button is grayed out until a folder containing a completed backup is selected - a folder you have just added with "CHOOSE/CREATE NEW BACKUP FOLDER" but have not yet backed up to will not enable Restore.
