# Plans directory

Canonical, version-controlled home for all planning docs (per AGENTS.md).
Tracked on dev as of 2026-07-24 — previously `.plans/` was gitignored, which
left per-checkout copies drifting across worktrees. Edit plans HERE (any
checkout of dev) and commit them like code; do not keep local-only copies.

- `modernization/` — the phased modernization program (0–5).
- `per-language-layouts/` — per-language Optimized layouts ("Spanish Phase 4"), smoke-tested & merged.
- `vietnamese/` — Vietnamese language support (design finalized, Phase 1 pending).
- `tooling/` — build/test infrastructure investigations.
- `archive/` — completed one-off session plans (auto-generated names).
