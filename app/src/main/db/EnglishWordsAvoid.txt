# EnglishWordsAvoid.txt — hand-curated word grading applied by BuildWordDbTask.
#
# Format:  word;tier[ marker]      tier is `profanity` or `slur`; the optional marker is
#                                  hand-added and overrides the tier.
#
#   (no marker)  Level 1, Offensive — in the DB, tagged CLASS_OFFENSIVE.
#   0            Level 0, Non-Offensive — in the DB, untagged. A false positive kept.
#   2            Level 2, Potentially Offensive — in the DB, tagged
#                CLASS_POTENTIALLY_OFFENSIVE.
#   PN           Proper noun: in the DB, Title-cased, CaseType TITLE_ONLY (Yamashita).
#   ACRONYM      Acronym: in the DB, UPPER-cased, CaseType ACRONYM (DOGE).
#   slur         Racial / ethnic / religious / anti-LGBTQ slur. NOT in the DB.
#   X            Excluded for any other reason. NOT in the DB; the entry stays here so
#                it keeps being excluded.
#   ?            Undecided — falls through to the tier (a `slur ?` entry stays excluded).
#
# Markers combine: `0PN` is Level 0 plus proper-noun casing. Whitespace is parsed
# loosely because this file is maintained by hand.
#
# The "Excluded Words" setting chooses which levels are withheld from predictions:
# None (nothing) / Offensive Words (Level 1, the default) / Potentially Offensive Words
# (Levels 1 and 2). Slurs and `X` entries are absent from the DB, so no setting reveals
# them. Nothing here restricts the user: any word can still be added to a personal
# vocabulary on-device, and this file never ships.
#

# sense tags + slur categories via Kaikki wiktextract (CC BY-SA 4.0), then graded by hand.
